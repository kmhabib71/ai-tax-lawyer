TRACK 1 – KNOWLEDGE PIPELINE (Week 1)
Goal: Feed the AI every rule, SRO, form and precedent it needs to reason like a human tax lawyer.

1.2 Chunk & embed

1.3 Metadata tagging  
Store in JSONB column:  
`{"section": "82C", "type": "penalty", "effective": "2023-07-01", "tags": ["advance-tax", "non-filing"]}`.

Code pointer (new file `lib/knowledge.ts`):
```ts
export async function searchKnowledge(query: string, topK = 5) {
  const embedding = await createEmbedding(query);
  const { data } = await supabase.rpc('match_documents', {
    query_embedding: embedding,
    match_threshold: 0.75,
    match_count: topK,
  });
  return data;
}
```
